# Contributing

All humans and coding agents follow the same contract:

1. Read **[AGENTS.md](./AGENTS.md)**
2. `./scripts/agent/preflight.sh` before implementation
3. `./scripts/agent/postcheck.sh` after implementation
4. Commits: Conventional Commits, **no** `Co-Authored-By` / AI trailers  
   (`docs/agent/COMMIT_CONVENTION.md`)
5. Install hooks once: `./scripts/agent/install-hooks.sh`

Details live under `docs/agent/`.
